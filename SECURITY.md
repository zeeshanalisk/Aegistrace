# Security policy

AegisTrace is a competition prototype. Please do not submit real customer logs, credentials or secrets as public issues.

For a security concern, contact the repository maintainer privately through the contact method listed on the repository profile. Include a concise description and a safe reproduction where possible.

Never commit `.env`, `.streamlit/secrets.toml`, API keys, production log files or personally identifiable information. The app is advisory and does not execute remediation actions.
